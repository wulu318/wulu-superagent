# 伍陆社区能力与 WorkBuddy 对照

参考腾讯公开产品页：<https://www.codebuddy.cn/work/>，查阅日期 2026-10-28。公开页面介绍了领域专家、多专家并行、多模型、桌面与 IM、MCP、自定义 Skills 和复杂任务交付。此对照不代表复制腾讯的内部实现或专家内容。

## 本次实现

- 社区创作者中心：用户投稿 Skill、MCP 连接器和专家套件。
- 独立人工审核、审核理由、版本重审、稳定上架快照、下架与审核记录。
- 已审核内容进入桌面端现有技能、连接器、专家套件市场。
- 修复远程 MCP 模板 URL 在安装表单中被清空的问题。
- 浏览器登录会话与创作者中心共用；App 浏览器登录成功后同步账号设置；账号登录即时持久化，套餐页使用后端实际返回结构。

## 后续需要分别验收的能力

现有代码中已有代理任务、子任务、模型配置、浏览器/文档产物、定时任务和 IM 入口。这些入口存在不代表已经全部完成与腾讯产品相同的体验。

后续功能应按以下验收目标推进：

1. 专家团队：一个目标可分配给多个不同角色，展示各自进度、汇总结果并可单独取消。
2. 工作流模板：从选择模板、填写参数到产物交付，支持重试与断点恢复。
3. 连接器授权：用户独立授权、撤销与连接测试，不把账号凭据放进共享模板。
4. 主动任务：定时执行、失败通知、运行历史和限额控制。
5. 企业共享：组织/团队可见范围、成员权限、组织审核与操作审计。
6. 产品体验：统一账号、可搜索的能力目录、收藏、安装升级提示和首个任务引导。

服务器上线、桌面端完整安装验证，以及这些后续能力都需要独立验证；不能仅以页面出现作为完成依据。
