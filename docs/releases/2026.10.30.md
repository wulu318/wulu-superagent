# 伍陆超级智能体 2026.10.30

- 技能、连接器和专家套件投稿集成到客户端，选择已有内容即可自动封装提交，无需寻找 ZIP、文件路径或编写 JSON。
- 支持查看自己的投稿、审核意见、修改重提、版本更新和撤回；管理后台负责审核与下架。
- 连接器分享时保留配置模板，去除已保存的环境变量值、认证请求头和常见密钥参数；技能打包排除本地凭据及运行缓存。
- 更新下载增加 SHA256 校验；Windows 增量更新在退出后替换文件，失败回滚，重启后可转用完整安装包。
- 修复 Linux 构建中的架构选择，分别打包 x64 与 ARM64。

## 更新说明

本版采用完整安装包更新，建立后续增量更新所需的兼容性基线。后续 Windows 更新只有在基础版本、Electron 和外部资源匹配时才使用增量包；运行时或原生依赖变化时自动使用完整安装包。macOS 与 Linux 使用完整安装包，以保留应用签名和 AppImage 的完整性。

社区投稿与审核需要服务器同步部署新版后端；客户端安装包发布与服务器部署是两个独立步骤。
